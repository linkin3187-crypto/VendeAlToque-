# Repositorio de redirección (Fase B)

Estos 2 archivos van en un repositorio **público nuevo** llamado exactamente `VendeAlToque-`
(el nombre viejo), **después** de renombrar y volver privado el repositorio del código.

- `index.html` y `404.html` son iguales: cualquier dirección vieja
  `https://linkin3187-crypto.github.io/VendeAlToque-/…` se manda a la misma página en `https://merkap.com.co/…`,
  con lo que va después del `?` (por ejemplo `tienda.html?id=12`) y del `#`.
- En el repositorio nuevo: Settings → Pages → «Deploy from a branch» → `main` / `(root)`.
- No lleva código de Merkap. Se puede dejar para siempre (gratis).
